# Better Ready Up

A small Risk of Rain 2 mod focused on multiplayer readying up. Unready, change the countdown or force everyone ready (as the host).

## Features

- **Ready / Unready:** Click again to unready and cancel the countdown.
- **Adjustable Countdown:** Defaults to 5 seconds, adjustable from 0 to 60.
- **Force Ready (ALL):** Hosts can ready everyone at once. Players can still unready afterwards.
- **Optional single player support:** Vanilla behaviour by default. Set the single player countdown above 0 to enable the mod's Ready / Unready features in solo.

![Force Ready](https://media.jectu.com/betterreadyup/force-ready.gif)

## Configuration

Change timers in the BepInEx config or with [Risk of Options](https://thunderstore.io/c/riskofrain2/p/Rune580/Risk_Of_Options/) (optional).

Both timers support 0–60 seconds. At 0, multiplayer starts instantly once everyone's ready.

Single player is left alone by default. If you want the ready / unready features in single player then simply set its timer to any value above 0.


## Translations

Supports all 12 game languages. Edit `translations.txt` and restart the game to change the translations. They're machine-generated, so corrections are welcome.
