# Changelog

## 1.1.3 
- Removed useless code that was doing the same thing twice
- Changed the log messages to be less goofy
- Slight Changes to README.

Sorry for all the updates over the first couple of days! This is my first time publishing a mod, so I've been learning as I go. Updates should be less frequent from here on.

## 1.1.2
- Single player defaults to vanilla behaviour again but you can enable unready for it by adjusting the config (old configs may not be changed with this update so if you wish to disable singleplayer features, set it to 0).
- Updated README to be less text heavy.

## 1.1.1
- Added localisation support for all 12 languages available in Risk of Rain 2.
- Added an editable `translations.txt` file to adjust the new text in other languages.
- Improved the logic for how the force ready button is generated so it can work in other languages.
- Added the GitHub repo link to the metadata.

## 1.1.0
- Added the unready features to single player to mimic coop. 
- Added a separate config option for solo (set solo to 0 to change it back to normal).
- Added optional [Risk of Options](https://thunderstore.io/c/riskofrain2/p/Rune580/Risk_Of_Options/) support.
- Updated `icon.png` and README.

## 1.0.1
- Improved README

## 1.0.0
- Added Ready / Unready toggle.
- Made ready up countdown configurable (defaults to 5 seconds).
- Cancels the ready up countdown when someone unreadies.
- Added host-only Force Ready (ALL) button.
